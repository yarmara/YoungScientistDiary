# Сборка и запуск

## Требования

- Настольная Windows x64 для запуска WPF-приложения.
- .NET 8 SDK x64 для сборки: [официальная загрузка](https://dotnet.microsoft.com/en-us/download/dotnet/8.0).
- Доступ к NuGet при первой загрузке зависимостей.
- Отдельный SQL Server и Microsoft Office не нужны.
- Для работы интерфейса рекомендуется экран от 1280 × 800; основные списки и формы прокручиваются.

`global.json` выбирает SDK ветки 8.0; более новые установленные ветки не заменяют его автоматически. Разрешены обновлённые feature bands .NET 8. Проверенная при подготовке версия SDK — **8.0.426**.

Приложение имеет цель `net8.0-windows`, `UseWPF=true` и `RuntimeIdentifier=win-x64`. Вычислительное ядро и проверки имеют цель `net8.0`. Проект не переведён на .NET 9 или .NET 10.

## Сборка одной командой

В командной строке Windows, открытой в корне исходников:

    build.bat

Для запуска без заключительной паузы:

    build.bat --no-pause

Сценарий последовательно выполняет:

    dotnet restore YoungScientistDiary.sln --locked-mode
    dotnet build YoungScientistDiary.sln -c Release --no-restore
    dotnet run --project tests\YoungScientistDiary.SelfTests -c Release --no-build
    dotnet publish src\YoungScientistDiary.App -c Release --no-restore --self-contained false -o dist\YoungScientistDiary

В публикацию копируются README, LICENSE, NOTICE, docs и licenses. Ошибка на любом обязательном шаге останавливает сценарий. Исходники не содержат bin/obj и загруженные пакеты: они создаются при сборке.

Запуск:

    dist\YoungScientistDiary\YoungScientistDiary.exe

Для обычной публикации целевой компьютер должен иметь **.NET Desktop Runtime 8 x64**. Обычного консольного .NET Runtime недостаточно для WPF.

## Автономная публикация

После успешного build.bat:

    publish-standalone.bat

Результат — `dist\YoungScientistDiary-standalone`. Эта папка включает .NET Runtime и Windows Desktop Runtime, поэтому на целевом компьютере их отдельно устанавливать не требуется. Правовые документы включённой среды выполнения копируются в `licenses/dotnet-runtime`. Не удаляйте их при распространении.

Переносите папку целиком. Настройки и исследовательские данные находятся в рабочем пространстве пользователя, отдельно от программы.

Сборка не использует trimming, single-file упаковку и Native AOT. Это сознательный выбор для совместимости WPF, SQLite и редакторов документов. Архив исходников не содержит подписанный установщик.

## Visual Studio

1. Установите версию Visual Studio с поддержкой .NET 8 и рабочую нагрузку разработки классических приложений .NET.
2. Откройте `YoungScientistDiary.sln`.
3. Назначьте `YoungScientistDiary.App` запускаемым проектом.
4. Выберите Release или Debug и выполните сборку.
5. Для получения переносимой папки используйте build.bat либо команду dotnet publish выше.

## Рабочая папка

По умолчанию: `%LOCALAPPDATA%\YoungScientistDiary`.

Явное указание отдельного рабочего пространства:

    YoungScientistDiary.exe --workspace "D:\ResearchDiary"

Если папка новая, программа создаст пустое хранилище. Если существующая база имеет неизвестную или более новую схему, программа откажется её открывать. Отсутствие последнего запомненного хранилища не приводит к созданию пустой замены: подключите диск либо укажите правильный путь.

## Если сборка не выполняется

| Сообщение / ситуация | Что проверить |
| --- | --- |
| dotnet не найден | Установите именно SDK .NET 8 x64 и заново откройте терминал. |
| Compatible .NET SDK was not found | Выполните `dotnet --list-sdks`. В списке должна быть ветка 8.0. |
| Не загружается NuGet | Проверьте доступ к источнику пакетов, прокси и свободное место. Повторите restore после устранения причины. |
| Ошибка locked-mode | Сверьте csproj с packages.lock.json. В исходном комплекте они согласованы. Если намеренно меняете зависимости, обновите lock-файлы и снова проверьте лицензии и тесты. |
| Не запускается обычная публикация | Установите .NET Desktop Runtime 8 x64 либо используйте автономную папку. |
| Отсутствует DLL или SQLite | Запускайте приложение из полной опубликованной папки, не копируйте один EXE. |
| Рабочая папка занята | Закройте другой экземпляр, использующий это же хранилище. |
| Нет права записи | Выберите доступную папку пользователя. Для обычной работы права администратора не нужны. |

Сценарии предназначены для cmd.exe Windows. Само ядро и SelfTests можно запускать на Linux/macOS, но WPF-интерфейс на этих системах не запускается. Установленный Windows targeting pack позволяет проверить компиляцию UI с другой ОС; это не заменяет проверку окна на Windows.

## Поддержка .NET 8

Ветка выбрана по требованию проекта. Перед последующим распространением проверяйте актуальность используемого SDK и Runtime на официальной странице Microsoft. Переход на новую основную ветку должен быть отдельным изменением со сборкой и проверкой сохранности данных; приложение не меняет целевую платформу самостоятельно.

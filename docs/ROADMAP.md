# Три этапа программы

Этот документ отделяет текущий результат от возможного развития. Сроки последующих этапов здесь не назначены.

## Этап 1 — реализован в этом комплекте

- WPF-приложение Windows x64 на .NET 8 с русским интерфейсом и выбором темы.
- Локальная SQLite, собственные копии файлов, история и корзина.
- Паспорт проекта, задачи, собственные страницы, дневник и версии протоколов.
- Календарь с часовой сеткой, повторениями и напоминаниями при запущенной программе.
- Библиотека источников, DOI, RIS/BibTeX/CSL JSON, дубликаты и профиль CSL для библиографии.
- Таблицы CSV/XLSX, неизменяемые версии, базовые статистические методы и графики.
- Отчёты, экспорт и полная проверяемая резервная копия с восстановлением.
- Учебный проект, исходники, инструкции, автоматические проверки и Apache License 2.0 для собственного кода.

Границы методов, CSL и текущей проверки UI перечислены в README и профильных документах. Полноценное замещение специализированной статистической системы или Mendeley не заявляется.

## Этап 2 — углубление исследовательской работы

| Направление | Возможное содержание |
| --- | --- |
| Статистика | Проверки предпосылок, ANOVA/Welch ANOVA, Манн–Уитни и Уилкоксон, Краскел–Уоллис, множественные сравнения, bootstrap, мощность и размер выборки. |
| Дизайн данных | Явные уровни независимых и технических повторов, длинный/широкий формат, повторные измерения, история очистки и преобразований. |
| Литература | Встроенный PDF-просмотр, выделения, заметки со страницей, матрица обзора, полноценный CSL-процессор с подтверждённой лицензией. |
| Планирование | Диаграмма Ганта, зависимости задач, более гибкие серии, импорт/экспорт ICS. |
| Документы | Настраиваемые шаблоны отчётов, составление статьи/диссертации из разделов, библиотека утверждённых стилей. |
| Надёжность и UX | Контрольный набор Windows UI-тестов, установщик, подпись сборки, схема миграций с предварительным архивом, настраиваемая политика хранения истории. |

Новые статистические методы должны сопровождаться независимыми эталонами, проверкой пропусков и численной устойчивости. Предположение о типе выборки нельзя выводить только из названия столбца или результата теста нормальности.

## Этап 3 — интеграции и работа команды

- Надстройка Word для вставки и обновления ссылок и библиографии.
- При необходимости — интеграция с LibreOffice и внешними календарями.
- Управляемый запуск R/Python для сложных моделей с сохранением кода, среды и результатов.
- Синхронизация рабочих пространств с версиями, конфликтами и передачей вложений.
- Роли, права доступа и журнал совместных изменений.
- Расширяемые пакеты шаблонов и модулей с проверкой происхождения и лицензии.
- Опциональный помощник для поиска и разбора материалов с явным выбором передаваемых данных и проверяемыми ссылками.

Эти функции потребуют новой инфраструктуры; они не включаются автоматически после настройки файла версии. Приоритет следует выбирать по реальным сценариям использования первой версии.

## Общее правило развития

Проект, исходные измерения, использованные методики и уже сохранённые результаты должны оставаться читаемыми после обновления. Новое вычисление создаёт новый результат; обновление шаблона не меняет уже сохранённую библиографию. Перед несовместимым изменением хранилища нужен полный проверенный архив.

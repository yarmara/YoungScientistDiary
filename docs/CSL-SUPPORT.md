# Литература и стили оформления в версии 1.0

В программе работает локальный обработчик **профиля CSL для списков литературы**. Это оригинальный компонент проекта под Apache License 2.0. Он не является полной реализацией стандарта CSL и не заменяет надстройку Word.

## Что доступно пользователю

- Редактирование карточек статей, книг, глав, диссертаций, материалов конференций, интернет-ресурсов, отчётов и патентов.
- Авторы, организации в качестве авторов, год, журнал/книга, том, выпуск, страницы, издательство, место издания, DOI, ISBN/ISSN, URL, дата обращения, язык, аннотация.
- Коллекции, теги, статусы чтения, собственные заметки и поля разбора исследования.
- Одна карточка может быть связана с несколькими проектами.
- PDF и другие файлы добавляются через кнопку «Вложения / PDF». Просмотр выполняется установленным приложением Windows; встроенные выделения в PDF в версию 1.0 не входят.
- Получение метаданных по DOI из Crossref с обязательным открытием полученной карточки для проверки. Это получение сведений о публикации, а не скачивание полного текста.
- Импорт и экспорт RIS, BibTeX и CSL JSON.
- Поиск предполагаемых дубликатов и объединение после просмотра двух карточек. Заполненные конфликтующие поля сохраняются из выбранной основной карточки; пустые дополняются, заметки и связи объединяются, вложения переносятся. Вторая карточка помещается в корзину.
- Формирование библиографии для выбранных строк или всех видимых строк при отсутствии выделения.
- Предварительный просмотр, копирование текста и RTF, экспорт TXT, RTF, DOCX и HTML.
- Сохранение списка как отдельного снимка: текст, порядок идентификаторов источников, идентификатор и SHA-256 стиля, RTF-вложение. Изменение карточек не переписывает сохранённый список.

## Встроенные шаблоны

1. **Русский числовой — базовый шаблон** — нумерованный список, авторы с инициалами, выходные данные статьи или книги, DOI либо URL с датой обращения.
2. **Автор — год — базовый шаблон** — сортировка по авторам, году и названию, год в круглых скобках.
3. **Английский числовой — базовый шаблон** — нумерованный англоязычный список с инициалами авторов.

Эти три шаблона написаны специально для программы. **Они не объявляются официальной реализацией ГОСТ, APA, Vancouver или правил определённого журнала.** До подачи рукописи сверяйте полученный список с конкретными требованиями.

## Загрузка CSL

В окне «Сформировать библиографию» нажмите «Загрузить CSL». Нужен независимый `.csl`-файл с разделом `bibliography`. После проверки файл сохраняется в папку `styles` рабочего пространства и входит в резервную копию.

Зависимый стиль содержит ссылку на родительский шаблон, а не полные правила. Программа покажет адрес родителя: загрузите соответствующий независимый CSL-файл самостоятельно. Автоматическое скачивание зависимостей не выполняется.

PDF/DOCX с требованиями журнала можно хранить среди материалов. Чтобы применять эти требования автоматически, необходим совместимый CSL-шаблон. Импорт текстового документа не превращает его в правила оформления.

## Поддерживаемые конструкции CSL

Используются пространство имён `http://purl.org/net/xbiblio/csl`, версия `1.0`, `1.0.1` или `1.0.2`. Поддержаны:

| Возможность | Поддержка |
|---|---|
| Структура | `bibliography`, один `layout`, именованные `macro`; циклические макросы отклоняются. |
| Текст | `text` с одним из `variable`, `macro`, `term`, `value`. |
| Группы | `group`, `delimiter`; группа, у которой все запрошенные переменные пусты, подавляется вместе с её постоянным текстом и аффиксами. |
| Условия | `choose`, `if`, `else-if`, `else`; условия `type`, `variable`, `is-numeric`, сочетания `match="all/any/none"`. |
| Авторы | `names variable="author"`, `name`, `name-part` для фамилии и имени, `substitute`, `et-al`; организации сохраняются как неделимые имена. |
| Имена | Порядок фамилии/имени, инициалы, дефисные инициалы, разделители, `and`, `name-as-sort-order`, `sort-separator`, `et-al-min`, `et-al-use-first`, `et-al-use-last`, формы `long`, `short`, `count`. |
| Даты | `date` для `issued` и `accessed`, явные `date-part` для года, месяца, дня; текстовый/числовой формат и `date-parts`. |
| Метки | `label` с `form` и `plural="always/never/contextual"`. |
| Числа | `number` в формах `numeric` и `roman`; числовые строки остальных видов остаются текстом. |
| Сортировка | `sort/key` по переменной или макросу, `ascending/descending`; числовые тома и выпуски сортируются по числовому значению. |
| Оформление | `prefix`, `suffix`, курсив/полужирный шрифт, подчёркивание, верхний/нижний индекс, кавычки, `strip-periods`; явные параметры вложенного элемента имеют приоритет над параметрами группы. `font-weight="light"` отклоняется; `oblique` отображается курсивом. |
| Регистр | `lowercase`, `uppercase`, `capitalize-first`, `capitalize-all`. Полный алгоритм англоязычного title case не заявлен. |
| Абзацы | `hanging-indent`, `line-spacing` 1–10, `entry-spacing` 0–10 в предварительном просмотре и форматированных экспортах. |
| Язык оформления | Встроенные русские и английские термины (`ru-RU`, `en-US`), переопределение терминов через `locale/terms/term`, формы единственного/множественного числа. |

Доступные переменные карточки:

`title`, `container-title`, `volume`, `issue`, `page`, `publisher`, `publisher-place`, `DOI`, `ISBN`, `URL`, `language`, `abstract`, `note`, `keyword`, `author`, `issued`, `accessed`, `citation-number`.

Публикационная дата в карточке версии 1.0 хранится с точностью до года. Поэтому `issued` не выдумывает месяц или день. Дата обращения хранится полностью.

Встроенные термины: `and`, `et-al`, `open-quote`, `close-quote`, `no date`, `page`, `volume`, `issue`, `author`, `accessed`, `retrieved`, `from`, `in`, `reference`, `online`. Другой необходимый термин нужно определить в `locale/terms` стиля; иначе оформление остановится с объяснением.

Для встроенных терминов доступны формы `long` и `short`. Формы `symbol`, `verb` и `verb-short` требуют явного определения в `locale/terms`; иначе программа сообщает о несовместимости. Отдельное сокращённое название источника в карточке не хранится, поэтому `text variable="title/container-title" form="short"` использует полное название. Проверяется допустимое расположение элементов: например, случайный `text` внутри `names` отклоняется при загрузке.

## Что отклоняется или не выполняется

Не поддержаны полная система внутритекстовых ссылок, группировка и свёртывание ссылок, устранение неоднозначности автор–год, годовые суффиксы `2024a/2024b`, повторные ссылки и позиционные условия, сортировка имён с частицами как отдельными метаданными, редакторы и переводчики, сведения об издании (`edition`), пользовательские локализованные форматы дат `locale/date`, диапазоны дат, гендерные правила терминов, порядковые числительные, `text-case="title/sentence"`, `second-field-align`, `display`, последующее замещение одинаковых авторов, автоматическое сокращение названий журналов, полное CSL-форматирование диапазонов страниц.

Неизвестные элементы, переменные и значимые атрибуты в используемом `bibliography` или его макросах приводят к сообщению о несовместимости. Неподдержанная конструкция не должна незаметно исчезать из вывода. Раздел `citation` не применяется; при его наличии показывается предупреждение. Метаданные `info` сохраняются в исходном файле.

Движок изолирован классом `CitationService`; в следующей версии его можно заменить или расширить без изменения карточек и сохранённых списков.

## Особенности обмена библиографией

- Предпочтительная кодировка — UTF-8. Некорректные UTF-8-байты не заменяются молча; программа попросит пересохранить файл. Для отдельного библиографического файла действует предел 32 МБ.
- Импорт создаёт новые локальные идентификаторы. Объединение с уже существующими карточками выполняется через проверку дубликатов.
- RIS поддерживает стандартные поля карточки, повторяющиеся авторы и ключевые слова, продолжения строк. Сведения о редакторах не входят в модель первой версии; при обнаружении показывается предупреждение.
- BibTeX поддерживает значения в фигурных скобках и кавычках, вложенные скобки, экранированные символы, составные значения через `#`, `@string`, авторов с `and` и корпоративных авторов в дополнительных скобках.
- Наследование полей BibTeX `crossref` не выполняется. Неизвестные строковые макросы сохраняются как текст с предупреждением. Полный TeX-интерпретатор не встроен; команды TeX требуют ручной проверки после импорта.
- CSL JSON поддерживает стандартные поля перечисленной карточки, авторов/организации и даты; поля, отсутствующие в модели версии 1.0, не сохраняются.
- RIS/BibTeX/CSL JSON служат обмену библиографическими сведениями. PDF, локальные коллекции, связи с проектами, история правок и все пользовательские поля не гарантированно переносятся этими форматами. Для переноса всей программы используйте полную резервную копию.
